# リングオシレータ型VCO
インバータ回路を奇数個接続することで発振させるリングオシレータ型VCOを作成しました。  
ただし、回路としては、6個（偶数個）だけ載せて、最後の一つは受講者のインバータ回路をパッド経由で繋げることで、完成する回路となっています。  
インバータ回路の利用法の一つを学ぶための回路となっています。
