# xschem カスタマイズ記録

更新日: 2026-09-10

設定ファイル: `~/.xschem/xschemrc`

ここまでの変更はすべてTcl設定によるもので、xschem本体は再ビルドしていない。

## 実装済み

### KiCad寄りのキーバインド

| キー | 動作 |
|---|---|
| `Ctrl+Z` | Undo |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Redo |
| `R` | 回転 |
| `E` | プロパティ編集 |
| `G` | 配線を維持して移動 |
| `Ctrl+D` | 複製 |
| `A` | シンボル配置 |
| `X` / `Y` | 水平／垂直ミラー |
| `L` | ネットラベル配置 |
| `I` | 図形線 |
| `Home` | 回路全体を表示 |
| `Backspace` | 選択アイテムを削除 |
| `Alt+Backspace` | 親回路へ戻る |
| `Ctrl+X` | カット |
| `Ctrl+A` | キャンバス上の全アイテムを選択 |

元のxschem機能と衝突した操作には、`Ctrl+Shift+R`などの代替キーも設定している。

### Ctrl＋左クリックの追加選択

- `Ctrl＋左クリック`を標準の`Shift＋左クリック`と同じ追加選択に割り当てた。
- `Ctrl＋左ドラッグ`も選択を追加する範囲選択になる。
- Ctrlクリックの連続操作ではプロパティダイアログを開かず、選択を継続する。
- `Shift＋左クリック`は引き続き使用できる。`Ctrl＋Shift`や`Ctrl＋Alt`の修飾状態は変換しない。
- 従来のCtrlクリックによるURL／コマンド実行とCtrlドラッグの動作は置き換わる。
- 実装: `~/.xschem/ctrl_select.tcl`をxschemrcから読み込み、描画ウィンドウの生成時に設定する。
- intuitive interfaceではShiftクリックが複製や配線開始にも使われるため、Ctrlによる追加選択イベントの処理中だけ本体のintuitive interfaceを無効化し、処理後に戻す。
- 実機確認: 別プロセスのXschemでCtrlクリックイベントを送り、配線2本・ラベルピン・SRAMの選択数が1→2→3→4になること、回路が変更されないことを確認した。
- 復元用: `~/.xschem/xschemrc.before-ctrl-select-20260910`

### 配線モード

```tcl
set infix_interface 0
set persistent_command 1
```

- `W`を押しただけではその場から配線を開始せず、クリックで開始する。
- 1本配置しても配線モードを維持する。

### 保存

```tcl
set no_ask_save 1
```

- `Ctrl+S`とFile → Saveは確認なしで上書き保存する。
- 未命名ファイルの保存先選択と、外部変更時の競合確認は残る。

### プロパティ・コード編集ダイアログ

- `Ctrl+Enter`でOKとして閉じる。
- `Shift+Enter`で、選択中の文字を改行で置換してから閉じる問題を防止した。
- 複数行・単一行編集欄の`Ctrl+A`を、行頭移動ではなく全文選択へ変更した。

### 前回セッションの復元

- 開いている既存の`.sch`一覧を`~/.xschem/last_session`へ記録する。
- 記録はxschemのイベントループから750 ms周期で行う。
- 通常起動時に前回の全`.sch`を同じ順序で復元する。
- ファイルをコマンドライン引数で指定した起動では、自動復元しない。

#### 終了前の未保存確認

- ウィンドウ右上の×を押した時点で、先に全タブの未保存状態を検査する。
- 未保存ファイルは、タブを閉じる前に一覧で確認する。
- Cancelなら1つも閉じない。
- OKなら、完全なタブ一覧を先に記録してから一括終了する。
- 終了途中のタブ一覧が750 ms監視によって上書きされないようにした。

### タブを閉じる操作

- 各タブに個別の×ボタンを追加した。
- タブ内の×は、そのタブだけを閉じる。
- ウィンドウ右上の×は、全タブを一括終了する。
- タブのドラッグ並べ替えを維持するため、閉じるボタンは既存タブボタン内に配置している。

### タブのドラッグ並べ替え

- 標準の「ドラッグ元とドロップ先を交換」する処理を廃止した。
- ドロップ先タブの左半分ならその手前、右半分ならその後ろへ挿入する。
- タブ列の空き部分または末尾の「＋」へ落とすと末尾へ移動する。
- ドラッグ元タブそのものが、タブ列の高さを保ったままポインタへ横方向に追従する。
- 候補位置には同じ幅の空き枠を置き、ドラッグ元の進行方向側の端が隣のタブの中心へ達すると、空き枠と周囲のタブをリアルタイムに移動する。
- カーソルのY座標がタブ帯から外れても判定を止めず、横方向に追従しているドラッグ中タブ自身の左右端で入れ替えを判定する。
- ドラッグ中に同じタブを複製した浮遊オーバーレイは表示しない。
- タブ列やアプリの領域外でボタンを離してもリリースを捕捉し、最後の候補位置へ確実に戻す。
- 明示的なマウス捕捉は常時表示されるタブコンテナで行い、一時的に非表示となるドラッグ元に対する`grab failed: window not viewable`を防ぐ。
- 見た目の並び順をセッションファイルにも保存し、次回起動時に同じ順序で復元する。
- 本体Tclが起動途中で`swap_tabs`を再定義するため、カスタム処理は別名で保持し、`user_startup_commands`から起動完了後にラッパーを設定する。

### シミュレーション端末

```tcl
set terminal {gnome-terminal --wait}
```

- xtermではなくGNOME Terminalを使用する。
- `Ctrl+Shift+C`でコピーできる。
- `Ctrl+Shift+V`で貼り付けできる。

## 撤回済み

### ホイール・トラックパッドのスクロール動作

2026-09-10に関連するカスタマイズをすべて撤回し、xschem標準の動作へ戻した。
水平パンの反転、ズーム刻みの変更、カーソル下の座標を中央に移す処理、マウスポインタのワープ、独自の修飾キー判定とデバッグ処理を削除した。

復元前の設定: `~/.xschem/xschemrc.before-scroll-revert-20260910`

### OS標準ファイル選択ダイアログ

一度はGNOMEのファイル選択ダイアログを使用する設定を追加したが、その後削除した。

現在の`Ctrl+O`、File → Open、Open in new windowは、xschem標準ファイルブラウザを使用する。

## 未解決

### 貼り付けプレビューの残像

次の操作で、設置前プレビューの輪郭がキャンバスに残る。

```text
Ctrl+V
→ W
→ Esc
```

範囲選択などで再描画すると消えるため、実データではなく表示上の残像と考えられる。

xschem本体の`abort_operation()`が配線キャンセルを先に処理してreturnし、貼り付け移動のキャンセル処理へ到達しないことが原因候補。configだけで安全に直すのは難しく、本体修正が必要。

### 貼り付けプレビューの初期位置

`Ctrl+C`後に`Ctrl+V`すると、貼り付けプレビューが現在のカーソル位置ではなくコピー元の位置へ現れる。

クリップボードへコピー元座標を保存し、`merge_file()`でその座標を復元している本体処理が原因候補。本体修正が必要。

### plotからシミュレーション画面を一括終了

ngspiceのplotウィンドウで`q`を押したとき、同じシミュレーションのplot群とngspice端末を一括終了したい。

plotはxschemとは別プロセスのngspiceが作るX11ウィンドウであり、キー入力もngspice本体の`x11.c`が直接処理する。ngspice 46+にはこのキーバインドを変更する設定がないため、xschemrcだけでは実装できない。ngspice本体の修正・再ビルド、または外部のX11ホットキーヘルパーが必要。

## セッション復元の現在の制約

次の状態は復元対象外。

- 未保存・未命名の回路
- 最後に選択していたタブ
- 各タブのズーム位置
- 選択中のアイテム
- Undo/Redo履歴

既存の`.sch`ファイル一覧と順序は復元する。
