# 検証結果

**現在の保存GDSに対する一覧は [validation_summary.json](validation_summary.json) です。**
列挙された26群が現在の合否の根拠です。最新の詳細配線試験名は`decoderfix_*`です。

`pd102_*`、`signalfix_*`、`layout_h*`などは途中候補・比較実験の履歴を含み、不合格も残しています。
ファイル名だけで現GDSの合格結果と判断しないでください。

元の検証記録が参照するハッシュやパスを保持するため、個別レポートは移動・一括置換していません。
経過は[EXPERIMENTS.md](../EXPERIMENTS.md)、短い説明は[VERIFICATION.md](../VERIFICATION.md)を参照してください。
