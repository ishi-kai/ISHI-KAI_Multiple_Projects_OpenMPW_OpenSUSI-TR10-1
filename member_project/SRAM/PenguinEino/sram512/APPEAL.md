# 仕様と工夫した点

## 狙い

教育用のOpenSUSI TR-1umプロセスで、600×1800 µmの枠へ、読み書きできるSRAMを
どれだけ収められるかに取り組みました。最終構成は**16行×32列・512 bit**です。
セルだけの配列に加え、行列デコーダ・プリチャージ・書き込み・センス・シリアル制御・
出力バッファを含めています。

## 1. 最小寸法の6TセルをPCellで配置

セルの全MOSはW=3.4 µm、L=1 µmです。元のPCellのsix_single版を維持し、
セルの繰返しピッチは22×29.6 µm、**651.2 µm²/bit**です。
最終GDS内のセルと元のPCellを全8図形層で比較し、形状の一致を確認しています。

| 面積の指標 | 値 |
|---|---:|
| セルのピッチ面積 | 651.2 µm²/bit |
| 512 bit分のピッチ面積合計 | 0.3334 mm² |
| 周辺回路・配線を含むコア外形 | 1776.7×600.0 µm = 1.0660 mm² |
| コア全体の面積÷512 bit | 約2082.1 µm²/bit |

セルのピッチと、タップ・周辺回路・配線込みの面積を分けて提示します。
他製品より高密度、あるいはTR-1umで初のSRAMという主張はしていません。

## 2. 7端子で512セルの任意の1bitにアクセス

VDD / VSS / CLK / RESET / SDI / WE / SDOの7端子で操作します。
アドレスをシリアル受信して内部で行・列をデコードするため、9本のアドレス線を
そのまま外部へ出す構成に比べて信号端子を抑えられます。

10bitの受信FFをアクセス中の保持にも使用し、アドレスを移し替える第2のFF列を省きました。
カウンタ5個＋受信10個＋制御／結果6個で、合計21個のFFです。

## 3. 列間で周辺回路を共有

32列をnMOSの列MUXで選び、書き込み用の片側プルダウンと7Tセンスアンプを共有します。
1回に扱うのは1bitです。書き込み駆動とセンスを各セルへ置く構成にせず、共有回路の
負荷と書き込み能力を、アレイ全体を接続したMOSシミュレーションで確認しました。

## 4. 動作を段階的に追える構成

外部CLKの18段階で受信とアクセスを進めます。内部発振器を使わず、
プリチャージ、書き込み駆動、WL、センス、出力保持の順序を回路図と波形で追えます。
論理の仕様をVerilogで記述し、PDKスタセルを明示的に接続した回路図と照合しています。

配置配線後には、長いポリ配線による非選択WLの持ち上がりや端子間電圧の超過を検出し、
金属接続の追加・配線幅の調整で改善しました。元の検査ルールを維持して確認しています。
最終提出には、編集可能な回路図、動作確認用TB、レイアウト、操作手順と検証条件を含めます。

## 評価の範囲

速度競争ではなく、限られた面積と端子数でSRAM全体の機能を実証する設計です。
詳細RC試験は周期5 µsの外部CLKで行い、限界速度は測定していません。
校正済み配線PEXや統計的ミスマッチ評価は含まれず、端子間電圧基準までの余裕が
約2.5 mVと小さい点を含め、詳細は[VERIFICATION.md](VERIFICATION.md)へ記載しています。
