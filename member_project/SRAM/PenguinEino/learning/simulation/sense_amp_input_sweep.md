# 7Tセンスアンプ：理想入力差の掃引

現在の `sram512/schematics/sense_amp_7t.sch` を `learning/schematics/sram_tb_sense_amp.sch` からネットリスト化し、VDIFFのみを変更。回路図の設定は変更していない。2026-09-10、ngspice-46+。

- VDD=5 V、27℃、出力負荷各10 fF、全MOS W/L=3.4u/1u。
- 素子ミスマッチなし、過渡ノイズなし、理想電圧源でBL/BLBを駆動。
- 一方を5 V、他方を5−VDIFF Vとし、100 ns周期で正負交互に4回判定。
- SAEの立上りは各周期40〜41 ns。70 nsにHIGH>=4.5 V・LOW<=0.5 Vを判定。95 nsに両出力>=4.5 Vのリセットを判定。
- default: 元の `tran 0.02n 400n`、ngspice既定の計算許容誤差。
- tight: `reltol=1e-7 vntol=1e-10 abstol=1e-15`、`tran 0.005n 400n 0 0.005n`。
- 遅延はSAEが2.5 Vを通過してから、正しい極性で出力差が4 Vになるまで。4回の最大値。失敗条件では遅延を記載しない。

| 入力差 | 厳しい計算設定での最大遅延 | 4回判定＋リセット |
|---|---:|---|
| 0.5 V | 1.964 ns | PASS |
| 100 mV | 3.023 ns | PASS |
| 10 mV | 4.483 ns | PASS |
| 1 mV | 5.924 ns | PASS |
| 1 µV | 10.242 ns | PASS |
| 1 nV | 14.561 ns | PASS |
| 1 pV | 18.914 ns | PASS |
| 0.1 pV = 1e-13 V | 20.248 ns | PASS |
| 1e-14 V以下 | — | 全4回は成立せず、極性が計算設定に依存 |
| 0 V | — | FAIL（意図するデータが存在しない対照条件） |

0.5 Vから1e-13 Vまで、試した両計算設定でPASS。1e-14 V近辺の失敗は実回路の感度を示さない。5 Vから差し引く演算の丸め、数値誤差、微小な履歴差が入力差に対して支配的になる領域であり、探索点間の厳密な限界値は求めていない。

小さな差ほど正帰還による判定に時間がかかる。左右対称・ノイズなしの理想条件で微小差を増幅できることは確認できるが、この結果から実チップの最小入力差や歩留まりを決めることはできない。
