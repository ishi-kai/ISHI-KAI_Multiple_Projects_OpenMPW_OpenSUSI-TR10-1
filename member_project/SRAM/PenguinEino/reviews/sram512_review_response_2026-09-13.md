# SRAM512 レビュー対応

2026-09-13。対象は[総合レビュー](sram512_review_2026-09-13.md)の検証ツールの不具合3件。
回路図・GDS・PDK・DRC/LVSルールは変更しない。

| 指摘 | 対応 |
|---|---|
| F1：変更後の回路へ古いPASSを流用できる | 各試験結果に、回路図・GDS・試験コード・PDKのハッシュを結び付ける。変更・記録欠落は`STALE`となり、合格扱いの提出物生成を停止 |
| F4：波形の不足を検出できない | 時間軸の有限性・単調増加・必要な開始／終了時刻を検査。測定区間の両端がない補間を拒否 |
| F5：SDOの途中の誤変化を見逃す | 読出し結果の取り込みとRESETの整定時間を除き、受信・書込み・待機中もSDOの保持を検査 |

## 確認方法

- 正常な保存波形は合格し、途中で切った波形と200 nsのSDO誤パルスは不合格になる。
- 回路・試験コード・PDK・結果が変われば、既存の合格記録を流用できない。結果を生成しないコマンドでは検証記録を更新できない。
- 回路図のMOS幅を変更した一時コピーで、検証集計と詳細版・提出版の生成拒否を確認する。元の回路と波形は変更しない。

**回帰試験8件は合格。変更した回路では26件すべてが`STALE`となり、両方の生成を拒否した。**
正常な入力では26件すべてが合格し、詳細版の生成も成功した。
数値と負例は[修正確認結果](../sram512/reports/verification_regression.json)に保存した。

```sh
python3 sram512/tools/test_verification.py
python3 reviews/sram512_review_checks.py --output build/sram512/review_resolution/negative_probes
python3 sram512/run.py summary
```

既存26件の結果は独立レビュー時点のハッシュと照合する。判定を変更した試験には保存波形から
新しい判定を適用し、`sram512/reports/rechecks/`へ別記録を残す。
刺激・回路生成コードが変わっていないことも比較しており、回路変更後の再計算を省く仕組みではない。
過去の試験を今回すべて再実行したという意味でもない。

今後は`sram512/tools/evidence.py --report <結果名> -- <検証コマンド>`で実行し、
実行前後の入力が一致し、結果が更新されて合格した場合に検証記録を作る。
`run.py digital`と`run.py layout-check`ではこの処理を自動で行う。

## 今回の範囲

使用条件は**5 Vに調整した安定化電源での実験用途**。
利用者の指示により長時間の追加シミュレーションを終了し、全セルの追加アナログ検証は打ち切る。
採用する検証範囲を拡大せず、回路変更は行わない。
F2・F3、および[追加回路レビュー](sram512_circuit_review_2026-09-13.md)の電圧余裕・RESETの順序・
セルのばらつきの懸念を、このツール修正で解決済みとはしない。
