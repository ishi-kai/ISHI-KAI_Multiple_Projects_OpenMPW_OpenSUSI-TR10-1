# OPAMPハンズオンをやってみて

ハンズオンでは、前の週に購入した **中古のSurface Go** でやってみようと思い持ち込んだのですが、当たり前ながら画面が小さい……。

Xschemの回路図を追いながら操作するのにかなり苦労し、ハンズオンはほぼ **Xschemの使い方を覚えたところで終了**しました。

出遅れたこともあり、おそらく大事な何かを聞き逃したまま、帰宅後に回路FIXを目指すことに。しかし、これがなかなかうまくいかない。

## まずはLを決める

そこで一度整理して、まず **L=1、2、3、4 µmの特性を調べ、L=2 µmで進める**ことにしました。

Lを固定した後は、基本的に **Wだけを調整して特性を合わせる**方針に変更。

試行錯誤の末、なんとかそれっぽい特性まで持っていけたので、次はレイアウトへ進みました。

## そしてKLayoutへ

ところが実のところ、**KLayoutもまともに使ったことがありませんでした**。

そのため、以前のインバータのハンズオン資料を引っ張り出し、基本操作から再スタート。

考えてみると、今回の募集資格にはまったくそぐわない状態でOPAMPのハンズオンに参加していたことになります（笑）。

## レイアウトは時間優先

レイアウトも、本当はガードリングを入れるなど、もう少しアナログ回路らしく作りたかったのですが、今回は時間切れ。

面積を徹底的に詰めることもせず、**まずは時間優先で回路をレイアウトし、LVSまで通す**ことを目標にしました。

## やってみると見えてくる

それでも実際に、

**回路を触る → 特性を見る → MOSサイズを変える → レイアウトする → LVSで回路図と照合する**

ところまで自分でやってみると、資料を読んでいるだけでは分からなかったことがいろいろ見えてきました。わかっていないところがたくさんあぶり出された感じ、、、

完成度という意味ではまだ改善したいところがありますが、**「とりあえず最後まで自分でやってみる」ことで得られたものは大きく、非常にいい体験になりました。**

ようやくハンズオンに参加できる資格が得られた感じです（笑）
