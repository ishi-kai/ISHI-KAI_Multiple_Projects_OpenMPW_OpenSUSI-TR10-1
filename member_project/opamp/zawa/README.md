## 工夫点

### 回路設計
- **ダブルテールラッチコンパレータ**を採用。1段目(MN_Mt1 + 差動対MN_M1/M2)でプリアンプ動作を行いFN/FPを生成し、2段目(MN_Mt2 + MN_MR1/MR2 + 再生ラッチMP_M7/M8・MN_M5/M6)で正帰還によりフルスイング判定を行う構成とし、キックバックノイズの低減とゲイン配分の柔軟性を狙った
- テールトランジスタ(MN_Mt1, MN_Mt2)は、駆動する差動対・ラッチ入力対の合計幅に合わせてサイジング(w=80u)し、動作マージンを確保
- 出力段は4段のバッファチェーンでラッチ内部ノードへの負荷を抑えつつ外部駆動力を確保

### レイアウト設計
- 全体を囲む**ガードリング**を追加し、電源タップとラッチアップ耐性を確保
- 感度の高いラッチノード(FN/FP)側のトランジスタはドレイン面積を最小限に抑え、正帰還の再生時定数への影響を抑制する一方、出力バッファ段はドレイン側を太くして駆動力とEM耐性を優先するなど、**ノードの役割に応じて非対称なレイアウト方針**を採用
