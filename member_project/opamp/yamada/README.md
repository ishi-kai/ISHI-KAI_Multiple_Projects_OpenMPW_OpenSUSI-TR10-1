# opamp

二日でOPAMP回路ハンズオン(8月15日、16日) 成果物

## 〇設計の説明

pMOS入力の2段Miller補償CMOSオペアンプです。素子単体の特性測定から始め、電流ミラーの基準素子を起点に順に寸法を決めました。

CL=100pF、Ibias=20µAの条件で、直流利得96.07dB、位相余裕60.5°、単位利得周波数3.23MHz、スルーレート501kHz、消費電力1.29mWとなりました。DRC・LVSともに合格しています。

## 〇工夫したポイント

バイアスレプリカによる温度補償です。XM9・XM10・XM11でXM7の動作点を複製し、補償抵抗XM12のゲート電圧を生成しています。温度が上がってgm7が下がるとRcも同じ向きに動くため、−40〜125°Cで位相余裕の変動が0.8°（60.3〜61.1°）に収まりました。

## 〇苦労したポイント

差動対にコモンセントロイド配置を適用したところ、素子を4ブロックに分割したことでN-Wellの分離距離が余分に必要になり、縦方向が規定の200µmに対してぎりぎりになってしまいました。ガードリングを入れる余裕がなくなり、実装を断念しています。
