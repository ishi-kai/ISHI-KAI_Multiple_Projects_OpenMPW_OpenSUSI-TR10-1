### 設計したオペアンプについて
GBWは2.5MHz、位相余裕は60°、開ループゲインは70dB程度です。十分な安定性を持たせることを第一に設計しており、ユニティゲインで飽和させても発振しないことを確認しています。

回路設計の工夫として、位相余裕を十分に確保したうえで、できるだけ高いGBWかつ、レイアウトがうまくいくように値を調整しました。また、トランジスタサイズは自分が配線できる最大サイズのギリギリを攻め、無駄なスペースが最小限になるようにしました。

レイアウトの工夫としては、ダブルビアを徹底し、ガードリングとダミートランジスタを入れることで製造のばらつきとノイズの影響を抑える工夫をしました。また、温度特性の向上ために、カレントミラーと差動増幅回路は可能な限り互い違いかつ左右対称な配置にしました。
また、基本的に縦方向の配線はM1、横方向の配線はM2で統一することで配線をシンプルにしながら、個別のトランジスタに対しビアをそれぞれ打つ余裕がないところはトランジスタの配置を工夫して1層のみで配線できるようにしました。

### 感想
回路設計については、スルーレートやGBW、最小・最大入力電圧などの仕様決定が難しく、求めた値がレイアウト可能なサイズを大幅に上回ったり、トランジスタサイズのバランスが大きく崩れたりして、再設計や調整を繰り返すことになったのが大変でした。
しかし、計算とシミュレーションをやり直すうちに、トランジスタの各パラメータと安定性や性能などとの関係が徐々にわかってきたので良かったと思います。

レイアウトでは、トランジスタサイズの自由度が高いため、配線のしやすさと性能のバランスを取るためにレイアウトと回路設計を行き来する必要があって大変でした。
