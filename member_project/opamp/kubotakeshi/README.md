# opamp
# 二日でOPAMP回路ハンズオン(8月15日、16日) 成果物

## 〇設計の説明
　Open Source Silicon Magazine Vol.2を参考に、性能測定用機器のDIYで紹介されていた治具が使えるよう設計を進めていました。しかし、確実に動作する確証が持てず、「人生でIC化に挑戦できるチャンスはこれが最後かもしれない」という思いから、最終的には確実に動く安全なサンプル回路を採用することにしました。。

## 〇工夫したポイント
　レイアウトの工夫: 直感的にわかりやすいレイアウトにするため、「Schematic to Place」の考え方を採用しました。
　レイアウトテクニック: 技術的なアプローチとして、今回はフィンガー構造（マルチフィンガー）のみを使用しています。

## 〇苦労したポイント
　当初は「規定サイズ（200×600）への集約」「ダブルVIA/コンタクトの多用」「フィンガー構造」「N-Wellの電位安定化」など、さまざまな設計にチャレンジしました。
　しかし、全体のレイアウトでLVSを通したところエラーが多発してしまったため、最小単位のブロックごとに分解して検証し、ひとつずつLVSをパスさせていく地道な作業に苦労しました。
　最終的には、時間の都合上「規定サイズへの集約」「N-Well電位安定化」の盛り込みは見送る形となりました。
