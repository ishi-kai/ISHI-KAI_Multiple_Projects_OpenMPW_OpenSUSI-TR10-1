#opamp作成 2日間ハンズオン(8/15,16)
#〇設計の説明
ハンズオンで紹介していただいたオペアンプを見ながら作成しました。
せっかく作るならということで、オーディオ用とより割り切った設計として
L=2umとしてWもできるだけ大きく作成しました。
結果一般的なオペアンプのようにDC付近のオープンゲインをより高くなり10Hzで80-90dBのオープンゲインになりました。
#〇工夫したポイント
オーディオ用途を強く意識して配線もできるだけ太くしました。
ビアもすべて２個以上配置しました。
DRCは配線の区切りでこまめに実行したので最後配線が完了したときのDRCエラーは0でした。
#〇苦労したポイント
配置したFETにBGがないぞ、どこにあるの?と悩みました。講師の先生のおかげで
「PMOSは(cont_n)をBGとして、NMOSは(cont_p)をBGとして使う」ということを知り
配置していき無事LVSをパスできました。
〇ISHI会の皆さんが、環境の構築をしっかりしてくださっているので
本来はもっと苦労するであろうところですが環境構築という面ではだいぶ楽をさせていただきました。
日々サポートもしてくださり本当に感謝の気持ちでいっぱいです。
