# OpenSUSI-TR10-Inverter-HandsOn

OpenSUSI TR-1um PDKを使用して作成したCMOSインバータの回路図・レイアウトです。

[2026年09月イベント：初めての半導体設計・製造体験！一日で作るインバータ回路ハンズオン](https://ishikai.connpass.com/event/407081/)で作成しました。

## 使用環境
環境構築は[ISHI会のセットアップスクリプト](https://github.com/ishi-kai/OpenEDA-PDK_SetupScript)を使用しました。

- OpenSUSI TR-1um
- xschem
- ngspice
- KLayout


## 感想

半導体のレイアウト設計をやってみたいとずっと思っており、今回ようやく機会に恵まれて参加できました。

丁寧に教えていただいたおかげで、DRCとLVSが通るところまで完成させることができましたが、正直なところ、まだあの構造でなぜFETとして動作するのか完全には理解できていません。

次の機会があれば、CPUのような大規模な回路や、LDO、温度センサなど、さまざまな種類の回路も作ってみたいと思いました。

自分で設計した回路が実際にチップになって帰ってくる日が楽しみです！！！
