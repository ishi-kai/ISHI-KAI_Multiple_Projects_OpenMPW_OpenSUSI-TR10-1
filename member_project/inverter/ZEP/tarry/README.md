# 感想！
普段はソフトウェアエンジニアとして開発しており、半導体についてはほとんど知識がありませんでしたが、興味を持って参加してみました。
実際に体験してみると、半導体の設計には深い知識が必要で、一つひとつの作業も非常に大変であることを実感しました。初めて触れる内容ばかりでしたが、分からない部分を丁寧かつ分かりやすく教えていただき、最後まで取り組むことができました。

普段扱っているソフトウェアとは異なる世界に触れ、コンピュータを支える技術を覗き見ることができ、とてもよい経験になりました。
