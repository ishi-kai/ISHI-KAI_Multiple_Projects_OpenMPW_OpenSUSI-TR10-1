## 感想
環境の準備段階で、早速VMware Fusionの入手時にBroadcomのアカウント検証で詰まり、
qemu-imgで配布イメージをqcow2に変換してUTMに移植するところから
始まりました(結果的に環境の仕組みに詳しくなれたので怪我の功名です)。

当日は環境を一度壊して再構築するトラブルもありましたが、
サンプルベースで進めてDRCは問題なくクリアできました。LVSではGDSのセル名と
spiceのサブサーキット名の不一致にハマり、「ファイル名では
なく中身の名前で照合される」というEDAツールの基本を学びました。

普段はAWSの管理業務、趣味でPCB設計(KiCAD)をやっていますが、
DRC/LVSの思想がPCBのDRCやIaCのdrift検出と地続きで、
レイヤーが変わっても工学の考え方は同じだと実感できたのが収穫です。
