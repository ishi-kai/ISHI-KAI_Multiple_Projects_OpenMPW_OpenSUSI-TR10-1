# Audio_OPamp_zawa

## 概要

**OpenSUSI TR-1um** を使用して設計した、オーディオ用途向けOPアンプのレイアウトです。

レイアウトを行い、アナログ回路としてのガードリングやダブルVIA/コンタクトを使用して、ノイズ対策、配線、電源構成を考慮して設計しています。
