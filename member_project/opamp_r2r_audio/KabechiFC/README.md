前々から気になっていたISHI会に今回初めて参加しました。

「無料でICを作れる」ということに興味を持ったのが参加のきっかけです。


普段は製品機器の回路設計をしており、
プリント基板の回路図や基板レイアウトには触れていますが、半導体設計はほぼ未経験でした。また、今回使用したLinux、xschem、KLayoutについても使い慣れておらず、環境構築から苦戦しながらの参加となりました。

実際に参加してみると、IC内部の設計といってもFETを作るところから始まり、物性・化学的な影響など、自分がこれまで触れてこなかった分野の前提知識が必要になることに驚かされました。

ハンズオンでは、xschemの回路図を見ながら、KLayout上でMOSFETやMOSCAPを配置し、M1/M2、コンタクト、VIAを使って実際のレイアウトへ落とし込む作業を行いました。

特に印象に残ったのは、回路図上では単純に見えるMOSFETも、実際のレイアウトではW/Lやフィンガー数、配置、配線方法などを考える必要があることです。面積を小さくしながら、対称性やノイズ、抵抗なども考慮する必要があり、「回路図通りにつなげば終わり」ではない半導体レイアウトの難しさと面白さを感じました。

また、M1とM2の使い分けやVIAの配置、配線幅・間隔など、製造ルールを意識して設計することも新鮮でした。

講義時間内には完成できませんでしたが、後日AB級アンプのレイアウト作業を続け、DRCを実行しました。

最初は38件のエラーがありましたが、斜めになっていた配線、M1/M2の幅や接続位置、コンタクトの微妙な位置ずれなどを一つずつ確認・修正し、最終的にDRCを0件まで減らすことができました。

特に、画面上ではほとんど分からない0.1 µm程度の位置ずれでもDRCエラーになることや、配線同士が見た目では接続されているように見えても、座標がわずかにずれていることで問題になることを実際に経験できたのは勉強になりました。

LVSについても実行し、レイアウトから抽出された回路と元の回路図を比較するところまで進めました。ただし、今回は `Netlists don't match` が残っており、完全に一致させるところまでは到達できませんでした。

DRCが「製造ルール上成立しているか」を確認するのに対して、LVSでは「作ったレイアウトが本当に回路図と同じ回路になっているか」を確認するという違いも、実際に操作することで理解できました。

今回は時間の都合もあり、差動増幅回路のレイアウトまでは自力で完成させることができませんでした。

それでも、これまで自分にとって未知だった「回路図から半導体の物理レイアウトを作り、DRC/LVSで検証する」という一連の流れを実際に体験できたことは、とても良い経験になりました。

そして技術そのものだけでなく、ISHI会に参加されている皆さんの技術力の高さと知識の深さにも驚かされました。それ以上に、「技術の面白さをみんなに知ってほしい」という姿勢や懐の深さに非常に感銘を受けました。

懇親会でも幅広い分野の知見に触れることができ、皆さんが純粋に技術を楽しんでいることも伝わってきて、とても楽しい時間でした。

まだ理解できていない部分も多いですが、今回作ったデータや講義内容を振り返りながら、MOSの構造、Wellやガードリング、コモンセントロイド、DRC/LVSなどについて、もう少し理解を深めていきたいと思います。

貴重な機会をありがとうございました。
