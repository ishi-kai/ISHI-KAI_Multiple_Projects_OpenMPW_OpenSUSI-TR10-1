# CONS / Half Adder CARRY

`cons.sch` は指定の4ゲート構成をそのまま実装しています。
既存の `nsign.sym` をNANYとして3個、`inverter.sym` を1個使用。

```
T  = NSIGN(A,B)
U  = NSIGN(B,T)
NA = INV(A)
Y  = NSIGN(NA,U)
```

3値に対してNSIGNは `-sat(A+B)`。9通りを離散値で照合し、YはA=BならA、それ以外0となることを確認しました。
CONSはHalf AdderのCARRYとして使用できます。SUMはこのセルに含みません。

## ファイルと端子

- `cons.sch`：階層セル。入力a/b、出力vout、inoutのV+/V-/V0。内部負荷なし。
- `cons.sym`：同セルを再利用する6端子シンボル。
- `cons_tb.sch`：上記シンボルを配置し、TB側へ10 fFを接続。V+=+5 V、V-=-5 V、V0=GND。
- `scripts/check_cons.py`：入力許容帯と全72遷移を追加検証するスクリプト。

単体TBは通常どおりLVSを無効にしてNetlist→Simulate。
A/B/vout/期待値と、内部T/U/NA/voutをそれぞれ純正ngspiceの電圧plotに表示します。
内部信号は `v(xdut.t)`、`v(xdut.u)`、`v(xdut.na)`。モデル・寸法は参照先のセルから取得します。

## 基本TB

27℃。DCはB=-5/0/+5 VごとにAを-5～+5 V、0.125 V刻みで掃引。
過渡は9入力を200 nsずつ保持し、最後に(-5,-5)へ戻る10区間、合計2 us。入力エッジ1 ns。
回路図に各区間のA/B/T/U/NA/Yと測定時刻を記載しています。
各区間終了1 ns前に内部信号と出力を測定し、期待論理電圧±0.5 Vで判定。
DCの36測定点と過渡の40測定点はすべてPASSでした。

DCの出力は以下のとおりです。

| A (V) | B (V) | Y (V、概数) |
|---:|---:|---:|
| -5 | -5 | -5 |
| -5 | 0 | 0 |
| -5 | +5 | 0 |
| 0 | -5 | -0.00249 |
| 0 | 0 | -0.00222 |
| 0 | +5 | -0.00249 |
| +5 | -5 | 0 |
| +5 | 0 | 0 |
| +5 | +5 | +5 |

論理は対称ですが、AにINVを通す構成なのでアナログ誤差や過渡特性はA/B交換に対して完全対称ではありません。

## 追加検証

`python3 scripts/check_cons.py` で再実行できます。
全72方向の入力遷移を100 ns区間、1 nsエッジ、解析刻み0.2 nsで試験します。
10 fF、100 fF、Aが2 ns遅れる、Bが2 ns遅れる、の4条件です。
最終値だけでなくT/U/NAも各区間終了1 ns前に照合します。

10 fFの全72遷移では、最悪整定時間は入力エッジ完了後約17.80 ns。出力の最大サンプル誤差は約2.50 mV。
100 fFでは約18.60 ns。整定は期待値±0.5 Vに入り続けるまでで、伝搬遅延や10–90%時間とは異なります。
Aが2 ns遅れる条件は約17.47 ns、Bが2 ns遅れる条件は約16.47 nsで整定。全4条件・計288遷移で内部信号と出力の測定値が期待値±0.5 V以内でした。
切り替え途中のグリッチがないことを保証するものではありません。

各理想入力から±0.5 Vの9領域（電源範囲内）を0.25 V格子でDC確認した結果、最大出力誤差は約26.5 mVでした。
これは27℃・±5 Vでの格子評価です。温度、製造ばらつき、外部負荷の最大値を保証する試験ではありません。

## 数値計算とログ

基本TBは `simulation/cons/`、追加検証は `simulation/cons_checks/` にネットリスト・ログ・データを保存します。
数値安定化の `rshunt=1e12` と階層内部の `.nodeset` を使用。
追加の全域二次元DC掃引では、RRモデルを含む回路に電源範囲を大きく外れる非物理的な根が現れたため、その結果は採用していません。
入力マージンは9つの論理領域に分け、各領域に対応するT/U/NA/Yを初期推定値として別々に求解して確認しました。
`.nodeset` は収束用の推定値であり、計算結果の電圧を固定する指定ではありません。時間的な履歴は別の過渡試験で検証しています。

DC領域ごとの再実行用ファイルは `dc/case0.spice` ～ `dc/case8.spice`。
各 `case*_view.spice` は同じ条件の純正plot付き版です。`dc/view.spice` は中央(0,0)付近を表示します。
過渡各条件も `view.spice` で再実行・表示できます。
