# NOT / NAND / NOR / NSIGN レビュー

現時点の保存済み `.sch` を再ネットリスト化して評価。回路の寸法・接続は変更していません。
NOTは `inverter.sch`。論理はNOT=-a、NAND=-min(a,b)、NOR=-max(a,b)、NSIGN=-sign(a+b)です。
NSIGNの重複pMOSはユーザー側で解消済み（XM5が残り、XM4は除去）。今回の結果は重複なしです。

## 結論と優先事項

1. **今回の静的条件では4回路とも論理レベルを再生できる。** 公称入力点だけでなく、入力の各論理電圧から±0.5 Vの領域でも出力誤差±0.5 V以内。ただし電源範囲内に限った0.125 V格子の評価で、連続領域の数学的保証ではありません。
2. **10 fF負荷の速度をそのままゲート接続時の速度として扱わないこと。** 実ゲート4入力を駆動すると、整定に最大約25〜43 ns。旧TBの20 ns区間末尾は十分な待ち時間とは限りません。
3. **入力切り替え途中は論理値を保証できない。** 2入力同時変化や2 nsのずれで、始点と終点の論理出力が同じでも大きく変動します。途中の入力組み合わせに対応した正当な論理変化と、容量・経路遅延による変動が含まれます。これらをすべて回路の誤動作と分類してはいませんが、非同期に出力を取り込む用途では問題になります。
4. **セル内の負荷容量とTBの説明が不一致。** NOT/NANDは保存済みセル内部に10 fF、NOR/NSIGNは内部負荷なし。`inverter_chain_tb.sch` は段1にも内部10 fFがあり、最終段は内部10 fF＋TB10 fF=20 fFです。旧説明をそのまま使うと負荷条件を誤解します。今回の単体比較は内部容量を含む合計10/100 fFに統一しました。

|---|---:|---:|---:|---:|---:|---:|
| NOT | 0.07 mV | 134 mV | 329 mV | 1.91 ns | 3.64 ns | 39.90 ns |
| NAND | 190 mV | 262 mV | 392 mV | 3.04 ns | 3.88 ns | 24.81 ns |
| NOR | 198 mV | 288 mV | 439 mV | 11.31 ns | 12.17 ns | 36.82 ns |
| NSIGN | 71.6 mV | 139 mV | 447 mV | 19.40 ns | 20.65 ns | 43.32 ns |

整定時間は最後の入力エッジ完了後、期待出力±0.5 Vへ入り続けるまで。立ち上がり時間・伝搬遅延とは異なります。
NOTは全6遷移、2入力ゲートは全72遷移。各状態100 ns、エッジ1 ns、過渡解析刻み0.2 ns。
実入力4個の負荷はNOT、NAND(A入力、B=+5 V)、NOR(A入力、B=-5 V)、NSIGN(A入力、B=0 V)を1個ずつ並列接続。DUT自身の10 fFも維持し、受け側出力には外部10 fFを付けています（NOT/NAND受け側は内部10 fFも残ります）。
各受け側の出力も区間末尾で確認し、すべて誤差0.228 V未満でした。最大駆動可能ファンアウトを求めた試験ではありません。

NSIGNの最悪遷移は論理入力(+1,+1)→(0,-1)。前回の約2〜6 nsは逆符号への4遷移だけの結果であり、全体の最悪速度ではありません。
重複除去後の(0,0)出力は約−71.6 mV。重複ありの過去の+31 mVを現在値として使わないでください。

## 温度・電源・入力許容領域

0/27/85℃ × 対称電源±4.5/±5/±5.5 Vの9条件を4回路で評価しました。
各条件の理想論理電圧はその電源電圧に追従させています（電源だけ変え、入力を±5 Vに固定した試験ではありません）。
入力を電源範囲内で0.125 V刻みに二次元掃引し、公称点・各入力±0.25/±0.5/±1 Vの領域を集計しました。

全9条件で、各入力±0.5 V領域の最大出力誤差はNOT 0.283 V、NAND 0.374 V、NOR 0.446 V、NSIGN 0.146 Vでした。
したがって、この格子評価では各ゲートが出力した±0.5 V以内の誤差を次段も受け入れる静的な条件を満たします。
厳密な静的ノイズマージンの抽出や、全回路構成での安定性証明ではありません。

±1 Vの広い領域は全条件では維持できません。例えば85℃・±5 VではNORが最大0.608 V、NSIGNが0.538 Vの出力誤差。
27℃・±4.5 VではNOTも最大0.512 Vとなります。温度・電源・入力ずれを含めた余裕は、公称点の誤差だけでは判断できません。
製造コーナー、ミスマッチの分布、配線抽出、非対称電源、電源投入、パッド/実装の寄生や外部チップ接続は未評価です。

## 実ゲートを6段接続

NOT → NAND(B=+5 V) → NOR(B=-5 V) → NSIGN(B=0 V) → NOT → NSIGN(B=0 V)。
各段は論理反転として動作します。各セルに保存されている内部容量を維持し、最終段へ外部10 fFを追加。
3値の全6方向の遷移と、論理0に±0.2/±0.5/±1 Vのずれを与える15区間を各200 nsで評価しました。
27℃/85℃、各区間末尾の全6出力、計180点すべてが期待値±0.5 V以内。

27℃で入力+1 V（論理0の摂動）は、段ごとに−0.286 → −0.104 → +0.214 → −0.085 → +0.021 → −0.073 V。
85℃で入力0 Vは、+0.051 → −0.154 → +0.304 → −0.071 → +0.074 → −0.053 V。
0 Vへの誤差が各段で単調に減るわけではありませんが、この接続では誤差が発散しませんでした。

## 同時切り替えと入力時間差

2入力ゲートについてBが2 ns遅れる場合とAが2 ns遅れる場合を、それぞれ全72遷移で追加評価しました。
すべて100 ns区間末尾には期待値へ整定します。ただし途中を観測すると、例えば以下が見られます。

- NAND: 論理(-1,+1)→(+1,-1)、終点/始点はともに+5 V。Bが2 ns遅れると一時的に約−3.26 Vまで落ちます。
- NOR: 論理(+1,-1)→(-1,+1)、終点/始点はともに−5 V。Bが2 ns遅れると一時的に約+4.58 Vまで上がります。
- NSIGN: 論理(+1,0)→(0,+1)、終点/始点はともに−5 V。Bが2 ns遅れると一時的に約−0.17 Vまで上がります。

途中で別の有効入力組み合わせを通るため、出力を切り替え直後から常に正しいものとして利用することはできません。
評価対象は非同期フィードバック回路やラッチではなく、整定後の組み合わせ論理です。

## 接続・モデル・TBの確認

- 全セルのPMOS bulkはV+、NMOS bulkはV-、RR SUBはV+。ネットリスト上の接続を確認。
- NOT/NAND/NORの既存単体TBは、セルのMOS/RR寸法とトポロジーに一致（内部自動ネット名の差は対応付けて比較）。NSIGNは既存TBがセルを階層参照。
- NSIGNの0 VクランプにはグローバルGNDを使用。今のシンボルはGND端子を表示していないため、階層化やチップのピン割当でも0 Vの電流経路が必要です。
- NANDは現状セルの入出力がlab_pin/vddで、階層接続用シンボルもありません。追加試験では現在のネットリストを明示的なポートを持つsubcktで包んで接続。将来の `.sym` 化ではポート定義が必要です。
- MOSモデルはAS/AD/PS/PDを内部でWとsdwidthから計算しています。回路図上の `as=0` 等の見た目だけから「寄生容量がゼロ」とは判断できません。ゲート負荷もモデルに含めて解析しています。
- RRを含むモデルが非常に大きな非物理的電圧へ収束することがありました。`rshunt=1e12` と `.nodeset` の初期推定値で再計算し、出力が有限かつ電源範囲付近にあることをチェック。混在6段では各インスタンスにも初期推定値を指定しています。非物理的解の結果を合格として採用していません。
- 既存TBだけでは全遷移、入力の両側同時摂動、実ゲート負荷、入力スキュー、温度と電源の組み合わせの確認が不足していたため追加しました。
- 消費電力は今回も合否条件にしていません。耐圧の保証を追加する評価でもありません。
