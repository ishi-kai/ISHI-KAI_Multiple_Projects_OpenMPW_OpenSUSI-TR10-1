# 平衡3値 SRAM セル試作

既存の `inverter.sch` を2個クロスカップルし、Q/QBで `(-5,+5)`、`(0,0)`、`(+5,-5) V` の3状態を保持する。INVの寸法は変更していない。

| 回路 | 内容 | TB |
|---|---|---|
| [ternary_latch.sch](ternary_latch.sch) / [.sym](ternary_latch.sym) | INV×2、4 MOS＋4 RR。アクセス素子なし | [ternary_latch_tb.sch](ternary_latch_tb.sch) |
| [ternary_sram.sch](ternary_sram.sch) / [.sym](ternary_sram.sym) | 上記＋NMOSアクセス×2、6 MOS＋4 RR | [ternary_sram_tb.sch](ternary_sram_tb.sch)、[ternary_sram_read_tb.sch](ternary_sram_read_tb.sch) |

電源はVDD=+5 V、VSS=−5 V。0 VはTBの基準電位で、セルにVMID端子はない。
WLは−5 VでOFF、+5 VでON。アクセスNMOSはW/L=3.4/1 µm、ボディはVSS。
Q/QBは記憶ノードの観測端子でもある。セル内部に明示的な負荷容量はなく、10 fFのQ/QB負荷はTB側にある。
プリチャージ回路とセンスアンプは含めない。

## Xschemで試す順番

各TBを開き、LVSモードを無効にして **Netlist → Simulate**。モデル読み込みと解析コードはTB内にあり、ngspice純正の電圧プロットを表示する。測定値と `PASS` / `FAIL` はngspiceのログに出る。
`../sram/learning/schematics/sram_tb_tran_write.sch`、`sram_tb_tran_read.sch` と同様、刺激源は回路図上の部品、シーケンス・期待値は右側の表、判定は `SIMULATION` に置いた。

### 1. 保持と有限外乱への復帰

`ternary_latch_tb.sch` は独立したラッチを3個置く。

| ラッチ | 初期 Q/QB [V] | 期待する保持 Q/QB [V] |
|---|---|---|
| x0 | −4.5 / +4.5 | −5 / +5 |
| x1 | +0.5 / −0.5 | 0 / 0 |
| x2 | +4.5 / −4.5 | +5 / −5 |

`.ic` で初期状態を設定し、通常の過渡解析を行う。`uic` は使わず、内部ノードは初期条件付きの動作点計算で求める。過渡解析中にQ/QBを理想電圧源で固定してはいない。
200–212 nsにQ→QBの+5 µA、500–512 nsに−5 µAの電流パルスを加える。各パルスは1 nsの立上り・立下りと10 nsの平坦部を持つ。
199 / 499 / 999 nsで、各ノードが期待電圧±0.5 V内にあることを確認する。

27 ℃の公称モデルでは3状態とも保持・復帰した。中間状態はQ/QBとも約+54 µV。
電流パルスによる最大変動は約35 mV。これは小さな有限外乱のテストであり、最大ノイズマージンを測った値ではない。
自動検証では、各記憶状態の周囲0.5 V以内でQとQBを独立にずらした計27初期条件も確認する。レール外へはずらさない。

### 2. BL/BLBによる書き込み

`ternary_sram_tb.sch` はBLとBLBを理想電圧源で駆動する。外部書き込み装置のモデルであり、セル内にドライバは入っていない。

```
Q: −5 → 0 → +5 → 0 → −5 → +5 → −5 V
QB: 常に反対の目標値。Q=0の書き込み時はBL/BLBとも0 V。
```

1スロット400 ns。初回以外はスロット開始+20–21 nsでBL/BLBを変更、+50–51 nsでWLを上げ、+150–151 nsで下げる。+299 / +399 nsで保持状態を判定する。
初期状態はQ/QB=−5/+5 V。異なる3状態間の全6方向を通る。
自動検証では同じ値への書き込みを含む全9組も独立に試し、さらにWLを下げた後でBL/BLBを反転して非選択時の保持を確認する。

### 3. 浮遊ビット線への読み出し

`ternary_sram_read_tb.sch` はBL/BLBに各10 fFの容量だけを接続する。BL/BLBを駆動する電圧源はない。
初期のビット線電圧は `SIMULATION` の `BLINIT=0 BLBINIT=0` で設定する。これは読み出し開始前の電荷を仮定した初期条件であり、プリチャージ回路を実装したものではない。

3つの記憶状態を別々に初期化し、0–200 nsはWL OFF、201–700 nsはWL ON、701–1000 nsは再びOFFとする。
699 nsの読み出し値と999 nsの保持状態を確認する。

| 記憶Q [V] | 読み出しBL [V] | BLB [V] | BL−BLB [V] |
|---|---:|---:|---:|
| −5 | 約−5 | 約+3.148 | 約−8.148 |
| 0 | 約+0.000054 | 約+0.000054 | 約0 |
| +5 | 約+3.148 | 約−5 | 約+8.148 |

正側のBLはNMOSアクセスの通過特性により+5 Vまで上がらない。このTBでは電圧差の符号・大きさと保持状態を確認する。±1の判定基準は差動電圧の絶対値>1 V、0は差動電圧と両ビット線電圧の絶対値<0.5 V。この判定はTB内の数値判定であり、センスアンプではない。
WL立上り時にはQ/QBに最大約0.80 Vの一時変動があるが、10 fF・BL/BLB初期0 Vでは元の状態へ戻る。

## 読み出し負荷による限界

Q/QB負荷10 fF、27 ℃、WL立上り1 nsのまま、各記憶状態についてBL/BLBの初期電圧を独立に−5/0/+5 Vへ振った。1容量条件につき3×3×3=27条件。

| BL/BLB各容量 | 正しく読み出し・保持できた条件 |
|---|---:|
| 10 fF | 27 / 27 |
| 100 fF | 25 / 27 |
| 1 pF | 11 / 27 |

100 fFでは、記憶Q/QBと完全に逆極性の電荷がBL/BLBに残った2条件で、±1の記憶が0へ変わった。
1 pFでは、両ビット線の初期電圧が0 Vでも±1の記憶が0へ変わる。逆極性へ反転する条件もある。
**このセルとアクセス寸法で、大きなビット線容量への非破壊読み出しが成立したとは扱わない。** アレイに広げる際は、ビット線容量・初期電圧・アクセス強度を改めて検討する必要がある。

## 再現と結果

```sh
python3 scripts/check_ternary_sram.py
```

- 最新の `.sch` からXschemでネットリストを作り直す。
- 回路図内の3つのTBをそのままbatch実行する（`plot`だけ除外）。
- 27初期条件、9書き込み組、読み出し81条件を追加実行する。
- [reports/ternary_sram.json](reports/ternary_sram.json) に測定値・合否・回路図/モデルのハッシュを保存する。
- 波形・SPICE・ログは `simulation/ternary_sram/` 以下。大容量の波形はGit管理しない。
- 終了コードと `nominal_passed` は10 fFでの基本動作を判定する。負荷探索の失敗は `read_characterization` と `all_characterized_reads_passed` に別途残し、合格に混ぜない。

作図生成コードは `scripts/build_ternary_sram.py`。通常の編集は `.sch` 上でよい。生成コードを再実行すると今回の7ファイルを上書きするため、手編集後は再生成しない。
今回の検証は公称モデルの回路図シミュレーション。SNMの定量抽出、素子ばらつき・PVT、レイアウト寄生付きの検証は含めない。
