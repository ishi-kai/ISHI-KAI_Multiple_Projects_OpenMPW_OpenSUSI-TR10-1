# 平衡3値 Half Adder

`half_adder.sch` は既存の `nany.sym` ×5、`inverter.sym` ×2を直接接続したセルです。
`half_adder.sym` の端子は a/b (in)、sum/carry (out)、VDD/VSS/VMID (inout)。
±5 V電源、VMID=0 V、論理−1/0/+1を−5/0/+5 Vに対応させます。

## 論理と共有部分

NANY(x,y) = −sat(x+y) として、次の構成です。

```
T  = NANY(A,B)
U  = NANY(B,T)
NA = INV(A)
C  = NANY(NA,U)   -> carry
D  = NANY(T,C)
ND = INV(D)
S  = NANY(ND,C)   -> sum
```

整定後の論理値について `A+B = S+3*C`。
CはCONSと一致します。TとCをSUM側で共有し、CONSの重複生成を避けています。
この7ゲート構成について確認したもので、全構成中の最小ゲート数を証明したものではありません。
primitiveの寸法はそれぞれ元の `.sch` を参照します。

CARRYは外部出力であると同時に、内部のNANY入力2個を駆動します。
Tも内部のNANY入力2個を駆動します。これらのモデルの入力容量を含めてシミュレーションしています。
セル内部に明示的な負荷容量はありません。

## 通常TB

`half_adder_tb.sch` をXschemで開き、LVSをOFFにしてNetlist → Simulate。
TB側に `Csum=10f`、`Ccarry=10f` を接続しています。
ngspice純正plotで3本のDC特性、SUM/CARRYの過渡波形と期待値、内部信号を表示します。

- DC：Bを−5/0/+5 Vに固定してAを−5～+5 V、0.015625 V刻みで掃引。
- 過渡：200 nsごとの全9入力組＋開始状態への復帰。入力遷移1 ns、計2000 ns。
- 各区間の終了1 ns前に測定。入力シーケンス・期待値・測定時刻はTB内に表記。
- T/U/NA/CARRY/D/ND/SUMの全7信号を、理想論理電圧±0.5 Vで判定。
- 期待波形の入力判定閾値は±2.5 V。遷移中の期待波形との不一致は整定時の判定とは別です。

27℃・±5 Vの通常TBでは、DC 63測定点、過渡70測定点が全てPASS。
DCのSUM/CARRYの最大誤差は2.575 mVでした。
ログ・波形データは `simulation/half_adder/`。

### DCの数値収束

粗いDC掃引と共通の初期推定では、内部ノードが数百V～それ以上へ飛ぶ非物理的な数値解が出ました。
採用したTBは掃引刻みを細かくし、B=0の掃引だけCARRY/SUMの `.nodeset` 初期推定を0 Vに変更しています。
`ha_cseed` / `ha_sseed` は収束補助であり、出力を固定する電源やクランプではありません。
過渡解析の前には元の推定値へ戻します。モデル・セル回路は変更していません。
採用条件で3本のDC掃引全点・全7信号が電源範囲内にあることも確認しました。

この初期推定は現在の回路・条件での対策です。寸法や条件を変えたときは数値解を再確認してください。

## 全72遷移の追加試験

`python3 scripts/check_half_adder.py` で再実行できます（numpy、xschem、ngspiceが必要）。
9状態間の異なる全72有向遷移を連続した入力列で試験します。
100 ns保持、入力エッジ1 ns。整定判定はSUM/CARRY両方が期待値±0.5 V以内に入り、その区間末尾まで留まること。
時間は最後の入力エッジの完了から測ります。内部7信号も各区間末尾で検証します。

結果は `simulation/half_adder_checks/results.json`、各ケースの `data.txt` / `run.log` に保存します。
各ケースの `view.spice` をngspiceで開けば純正plotでSUM/CARRYを表示できます。

|---|---:|---:|---:|---:|
| 各出力10 fF・同時入力 | 72 | 2.640 mV | 35.23 ns | 0 |
| 各出力100 fF・同時入力 | 72 | 2.632 mV | 35.83 ns | 0 |

全条件でPASS。値は27℃・±5 V・公称モデルの結果です。温度/電源/製造ばらつきの追加評価は今回含めていません。
遷移中のグリッチや一時的な電源範囲外へのオーバーシュートはあります。上記は整定後の論理動作の確認であり、無グリッチの保証ではありません。
