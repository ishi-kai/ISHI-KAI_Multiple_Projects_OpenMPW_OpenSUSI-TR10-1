# NSIGNの寸法調整

`nsign.sch` へ反映済み。`nsign.sym` と `nsign_tb.sch` は階層参照するため、同じ寸法を使用します。
論理は `y = -sign(a+b)`、V0=0 V。消費電力は選定条件から除外。MOS長は1 µm、RR幅は2.8 µmに固定し、主回路・0 Vクランプを別々に調整しました。

| 部品 | 対象 | 変更前 W/L (µm) | 採用 W/L (µm) |
|---|---|---:|---:|
| 主回路pMOS | XM3, XM5 | 46 / 1 | **34 / 1** |
| 主回路nMOS | XM1, XM2 | 16 / 1 | **11 / 1** |
| 0 VクランプpMOS | XM6, XM8 | 46 / 1 | **14 / 1** |
| 0 VクランプnMOS | XM7, XM9 | 16 / 1 | **8 / 1** |
| 上下RR | R1, R2 | 2.8 / 17 | **2.8 / 16** |

RRはPDKの表示式で各約4.62→4.13 kΩ。`R=1` は変更していません。
寸法面積の目安（全素子のW×Lの合計）は **343.2→223.6 µm²、約34.8%減**。コンタクト・ウェル・配線を含む実レイアウト面積の削減率ではありません。
セル内部の負荷容量は追加せず、単体TB側の10 fFで比較しています。

## 公称条件の比較

27℃、±5 V、入力−5/0/+5 V。DCは入力A/B両方を0.125 V刻みで掃引。

| 指標 | 変更前 | 採用値 |
|---|---:|---:|
| 公称9点の最大出力誤差 | 71.6 mV | **2.49 mV** |
| 各入力±0.5 V領域で最大出力誤差 | 138.8 mV | **135.3 mV** |
| 各入力±1 V領域で最大出力誤差 | 446.8 mV | **334.7 mV** |
| 最悪立ち上がり（10–90%） | 15.76 ns | **6.15 ns** |
| 最悪立ち下がり（10–90%） | 7.75 ns | **7.23 ns** |
| 最悪整定時間 | 19.23 ns | **7.58 ns** |

出力(0,0)は約−2.49 mV、逆符号は両順序ともほぼ0 V、残りは±5 V。
入力±1 V領域の出力誤差は改善しましたが、0.125 V格子で判定する一様入力許容幅は新旧とも±1 Vまで。マージン幅そのものが大きく拡大したとは主張しません。
領域は電源範囲内に限定し、各論理値から両入力が同時にずれる場合を含みます。格子評価であり、厳密な静的ノイズマージンの抽出ではありません。

過渡は全72方向の入力遷移、各区間80 ns、入力エッジ1 ns、刻み0.1 ns。
立ち上がり/立ち下がりは出力が変わる遷移の実測定常値間10–90%。
整定時間は最後の入力エッジ完了から期待値±0.5 Vへ入り続けるまでで、出力が変わらない入力遷移も含みます。
前回レビューと比較条件が少し異なるため、変更前も同一条件で再計算しています。

## 負荷・温度・入力時間差

- 100 fF、27℃：最悪立ち上がり7.18 ns、立ち下がり7.69 ns、整定8.52 ns。
- 10 fF、85℃：最悪立ち上がり7.27 ns、立ち下がり8.28 ns、整定8.73 ns。全72遷移の区間末尾誤差は最大約53.2 mV。
- Aが2 ns遅れる/Bが2 ns遅れる全72遷移：いずれも整定。最大整定時間は約7.58/6.74 ns。
- 実入力4個（NOT、NAND、NOR、NSIGNを各1）と10 fFを駆動：最悪整定約24.99 ns、区間末尾のDUT誤差は最大約2.51 mV。受け側の論理出力も確認。
- NOT→NAND→NOR→NSIGN→NOT→NSIGNの6段接続、27/85℃：入力3値と中央への±0.2/±0.5/±1 Vの摂動を含む15区間、各200 ns。全段の180測定点が期待値±0.5 V以内。
- 実際の `nsign_tb.sch` の9入力＋逆符号履歴試験も再実行し、全17測定点が合格。

## 温度・電源変動とのトレードオフ

0/27/85℃ × 電源±4.5/±5/±5.5 Vの9条件を0.125 V格子で再検証。
入力の理想値は電源に追従させています。
各入力±0.5 V領域の出力誤差は全条件で0.5 V以内、最悪約**0.299 V**。
変更前の同領域の最悪約0.145 Vより悪化しており、小型化に伴う余裕の減少です。

±1 V領域まで保証する選定ではありません。例えば85℃・±4.5 Vでは最大誤差約0.869 V、85℃・±5 Vでは約0.524 V。
公称27℃・±5 Vでの平坦さ・精度・速度と小型化のバランスを選び、温度/電源変動時は±0.5 Vの入力帯を確保しました。
製造ばらつき、配線抽出、パッド、実装、電源投入、非対称電源は未検証です。切り替え途中のグリッチをなくす変更でもありません。

## 探索と再現

粗探索235組、主回路近傍90組、追加の最終候補とクランプ寸法を比較。
最小寄りのクランプ3.4/3.4 µmは主回路と組み合わせると整定が約29 nsまで遅くなる候補があったため不採用。
クランプを14/8 µmとすることで、全体の小型化を保ちつつ立ち上がり・立ち下がりの悪化を避けました。
大域最適や最小レイアウト面積を保証する探索ではありません。

`simulation/nsign_tuning/` に元回路、探索用ネットリスト、候補一覧、選定値、DC/過渡データ、ログを保存。
各保存条件の `view.spice` は純正ngspiceの電圧plotを使用します。
数値安定化は `.options rshunt=1e12` と内部ノードの `.nodeset`。非物理的な電圧や解析エラーは候補から除外します。

探索コードは `scripts/tune_nsign.py`。選定値と変更前を再確認するには:

```sh
python3 scripts/tune_nsign.py --validate
```

探索時の `simulation/nsign_tuning/nsign_tb.spice` を回路のテンプレートとして使います。粗探索の再実行は引数なし。
追加探索スクリプトは同フォルダの `refine.py`、`finalists.py`、`clamp_refine.py`、実接続の検証は `system_check.py` です。
